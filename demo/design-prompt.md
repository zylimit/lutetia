# Prompt for Open Design (paste as-is; Agent = Codex)

Design a single-file, fully offline web dashboard: **"Ariane project board"** for Orange France. Audience: Orange project managers and Huawei project team, on a 1440 px desktop (meeting room, projector) and an iPhone (375 px, added to Home Screen, must feel like a native app). Language: English. It must look cool and professional — a control-room feel, not a SaaS card kit.

## Context (why it exists)
Huawei and subcontractors (Hovia, AB RSX, RC) dismantle old copper cable across France for Orange and recover the copper. Thieves lift manhole covers to dig out cable and sell the copper, so every manhole carries a sensor; copper bundles carry GPS trackers. The board answers: how many tonnes are planned and where, which weeks are site audits scheduled, which manhole moved in the last 24 h, where are the copper bundles. A hand-made earlier version failed: five identical big-number cards, big empty areas, a bar chart with one bar, filters taking the first screen, three unrelated map styles, zeros everywhere. Do the opposite.

## Look (these tokens are the starting point; you may refine within the same mood)
Deep navy workstation. Surface #0E1726, raised #16223A, hairline #26344F, text #E8EDF5, secondary #9AA8BF. **Copper #D08A4E is used only for tonnes** (numbers, bars, map dots sized by planned tonnes) — no other meaning. Status: ok #3FB6A8, warn #E8B04A, alert #EF5A5A, focus ring #7FB2FF. System sans-serif stack, tabular numbers. Radius 6 px panels, 3 px tags. Panels separated by hairlines, no drop shadows, no gradient backgrounds.
**Be bold in exactly one place: the hero map** — a high-fidelity inline-SVG map of France (real regional outline, not a rough polygon) with the two regions AURA (Auvergne-Rhône-Alpes) and OUEST (Pays de la Loire) highlighted, copper dots sized by planned tonnes, manhole markers (circle = online, hollow = offline, triangle = moved in last 24 h), and thin copper lines linking sites to their region. Everything else stays restrained. Motion: only a slow pulse on a manhole that moved (static double ring under prefers-reduced-motion).
Avoid: ALL-CAPS eyebrow labels, dot-separated meta strings, arrows at the end of button text, every card fading in, one radius everywhere, purple gradients, big-number-small-label hero cards.

## Pages
1. **Sign in** — account chips Orange / Huawei (read-only) and Operations (admin), username, password, "Keep me signed in for 30 days" (checked). Demo accepts any password.
2. **Overview** — fits 1440×900 without scrolling. Left: demolition plan (31 POI work orders, 47.5 t planned copper in copper colour, 52 cable segments, 48.0 km, per-region table AURA/OUEST, bars per subcontractor). Centre: the hero map with France / AURA / OUEST switch. Right: OCC site audits for the next 4 weeks (W46–W49, POI count per week, then the next audits grouped by subcontractor), copper bundles (2 of 5 GPS online, last position, tiny 7-day track sketch). Bottom: manhole security block — "10 / 12 sensors online", alert strip "1 movement in last 24 h / 1 low voltage sensor", the three latest movement events. Tapping any block opens its page.
3. **Demolition plan** — filter chips (UCI, subcontractor, commune, category Transport/Distribution, underground/aerial, cable type) collapsed into "Filters (n)"; planned tonnes by subcontractor and by cable type as horizontal bars; OCC site-audit timeline (one bar per POI, rows per subcontractor, weeks W46–W51); POI table with expandable cable segments; Export CSV (works, synthetic data only); SLA process reference (tabs Transportation / Distribution 15 steps, MASSIVE 19 steps; each step shows owner Customer / Huawei / Partner by shape, not only colour). **Never show actual weight or completion rate.**
4. **Manhole security** — map plus movement-event timeline (IMEI, start, duration, flips) and a table of 12 sensors (status, location with an amber "location unverified" tag, voltage, signal, last report, events in 7 days). A movement event merges all alarmFall flips within 30 minutes.
5. **Copper bundles** — map with the 5 GPS devices (2 expected online), 7-day track toggle, device list.
Phone: top bar (name, refreshed time, refresh), bottom tab bar Overview / Demolition / Manholes / Copper, tables become cards, map full width, touch targets ≥ 44 px, no horizontal scroll at 375 px, add manifest and apple-touch-icon metadata. States (switchable from one small control that must never cover content): normal, loading skeleton, empty (with "Clear filters"), error (shows last data + Retry), offline ("Offline · data as of 08:42"), session expired.
