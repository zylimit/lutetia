# Ariane 项目看板 Demo · 设计计划（两遍法）

来源：Product-Spec.md v1.8（SCOPE-14 ～ 18、SC-10 ～ 13、FLOW-4 / 5、UI 与使用情境）。
**未经 Design-Brief.md / DESIGN.md**：用户 2026-11-07「先出 DEMO」，在 Brief 之前出；token 临时从 Spec 抽，Demo 看过后回 /design-brief-builder 补 Brief 与 DESIGN.md，本文 token 作为起点。
生成路：本机无 odc、无浏览器引擎 → 不走 odc / 提示词模式，由 implementer 手写单文件 `demo/index.html`（用户要立刻能看）。UI 审计缺席。
数据：全部合成，格式照 data/poi/ 的真表（UCI、分包商、市镇、电缆型号、OCC 写法、IMEI 取自 Spec 已公开的 12 台）；不含任何真实重量、日期、地址，可入库。

## 方向（只出一个，用户看过再决定要不要比较）
「拆除作战室」：深海军蓝工作台 + 铜色。产品世界里最有特征的东西是**铜**与**地理**——拆下来的是铜，防的是偷铜，工地散在法国两个大区。
- 首屏开在：法国示意图（两大区 AURA / OUEST 的站点，圆点大小 = 计划吨数）+ 井盖防盗状态，不是一排大数字卡。
- 大胆一处：铜色只给「吨数」这一个语义（计划吨数的数字、图上圆点、条形），全页没有别的地方用铜色。
- 动效只留一处：有挪动事件的井盖标记做一次慢脉冲（reduced-motion 下改为静态双圈）；其余只有用户触发的展开 / 切换。

## 八态（每页）
空（筛选后无结果：给「清除筛选」）、加载（骨架）、成功、错误（数据口失败：显示上次数据 + 重试）、冲突（不适用：只读）、离线（「Offline · data as of 08:42」）、无权限（会话过期 → 回登录）、AI 工作中（不适用：无 AI）。Demo 右下角一个「演示状态」切换器可切这些态。

## 通病自审（原本 → 改成 → 为什么）
- 首屏五张大数字卡（Demo 原样）→ 地图为主、数字只占左栏 → 「大数字+小标签」是首屏通病，产品最有特征的是地理与铜。
- 近黑底 + 单一酸绿 → 海军蓝底 + 铜色只给吨数 → 避开聚簇 2，铜色有业务含义。
- 卡片一律同圆角同灰影 → 面板靠发丝线分隔、无投影、圆角 6 / 3 分级 → 避开 SaaS 卡片套件。
- 每段淡入 → 只留井盖脉冲一处。
- ALL-CAPS 眉标、中点串、按钮尾巴「→」→ 不用；顶栏「Ariane · Orange France」是品牌名例外，仅此一处。

## 模拟边界
Demo 全部本地：数据写死在页面里，筛选 / 切页 / 展开 / 切账号 / 切状态只改页面显示，不请求任何后端；「导出 CSV」真的在浏览器里生成文件（只含合成数据）；登录不校验密码（演示）；刷新后回初始状态，右下角「重置演示」同效。
